# 02 · 交互与视觉设计

对应可操作样稿：[design/index.html](../design/index.html)。设计变量见 [tokens.json](../design/tokens.json)。

## 1. 设计方向

暂定名称：**言桥 / E_ShuRu**。视觉以暖白、深墨色、低饱和青绿为主，讲解区域用浅暖灰区分。界面要像日常可用的 Windows 输入工具，而不是聊天机器人或学习仪表盘。

信息顺序始终为：**中文意图 → 英文表达 → 需要时再看解释**。主要操作直接叫“输入中文”“输入英文”，避免将插入文字命名为“发送”。产品中不出现点赞、收藏、历史、扬声器等入口。

## 2. 界面组成

| 界面 | 用途 | 何时出现 |
|---|---|---|
| 输入浮窗 | 句子编辑、拼音候选、单条英文、提交按钮 | 有活动输入会话时 |
| 词句讲解区 | 解释当前英文的关键表达 | 用户主动展开时，属于同一个浮窗 |
| 设置窗口 | 配置个人 API Key、测试连接、外观设置、快捷键说明 | 托盘或浮窗设置入口 |
| 托盘菜单 | 打开设置、查看连接状态、退出辅助进程 | 用户会话中 |

不设置独立首页、学习中心、历史页或收藏页。HTML 原型中的侧边场景导航、桌面背景、示例按钮和检查说明仅用于展示设计。

## 3. 输入浮窗布局

```text
┌──────────────────────────────────────────────────┐
│ 言桥  ·  全拼                           ● 已连接  ⚙ │
│                                                  │
│ 中文  ·  句子编辑区                                │
│ 我今天累坏了，想早点睡。                             │
│ shui   [1 睡]   2 水   3 税   4 谁                 │ ← 仅有拼音时出现
├──────────────────────────────────────────────────┤
│ ENGLISH                                   ● 就绪 │
│ I'm beat. I think I'll turn in early tonight.     │
│                                                  │
│ 词句讲解 ⌄    Ctrl+J                              │
├──────────────────────────────────────────────────┤
│ [输入中文  Enter]            [输入英文  Ctrl+Enter] │
└──────────────────────────────────────────────────┘
```

示意候选内容不是词库承诺，实际必须使用拼音引擎输出的真实候选。没有活动拼音时不显示伪候选；中文编辑区与英文区仍同时存在。

### 尺寸与位置

- 使用 DIP 设计、实际以 Per-Monitor DPI Aware V2 适配。
- 标准宽度 560 DIP，舒适阅读上限 640 DIP；紧凑宽度 440 DIP。
- 无讲解时高度约 280–360 DIP；正文变长可增长，但不超过当前显示器工作区高度的 70%。
- 中文编辑区初始 2 行，最多展示 4 行后内部滚动。英文最多展示 4 行后内部滚动。讲解区独立滚动，不能挤掉提交按钮。
- 锚点为宿主插入光标，默认在光标下方偏移 8 DIP，尽量不遮挡当前行。
- 下方空间不足时向上展开；左右边界限制在当前显示器工作区内，安全边距 8 DIP。
- 讲解沿相同锚点展开；若浮窗需上移，保持靠近输入位置，不跳到另一个显示器。
- 无法获取光标位置时，回退至当前宿主窗口内的最近有效锚点；不轮询读取全文来定位。

## 4. 视觉规范

| 项目 | 浅色 | 深色 |
|---|---|---|
| 基础背景 | `#F5F6F3` | `#171E1D` |
| 面板 | `#FFFFFF` | `#222B29` |
| 主文本 | `#1D302B` | `#EAF2EE` |
| 次级文本 | `#61736B` | `#A7BBB0` |
| 主操作 | `#25634F` | `#9AD6B8` |
| 主操作文字 | `#FFFFFF` | `#142D22` |
| 讲解底色 | `#F7F5EE` | `#2D3028` |
| 分割线 | `#DFE6DF` | `#3C4842` |
| 错误 | `#A23B38` | `#FFB4AB` |

- 字体：中文优先 Microsoft YaHei UI，拉丁字符优先 Segoe UI Variable / Segoe UI，不加载网络字体。
- 中文正文 16 / 25，英文正文 20 / 30，讲解 14 / 22，辅助标签 12 / 18（字号 / 行高，DIP）。
- 标准圆角：面板 14、子区域 10、按钮 8。外层柔和阴影，不叠加大面积毛玻璃。
- 间距采用 4、8、12、16、20、24 的序列。
- 文字与背景对比度目标至少 4.5:1；重点操作和焦点框用颜色与形状共同区分。
- 键盘焦点使用可见描边；禁用按钮既改变样式，也暴露禁用语义。
- 常规过渡 120–160ms，只用于展开与按钮反馈；不对每次文字更新做位移动画。尊重减少动画、高对比度设置。

## 5. 中文编辑和快捷键

| 操作 | 有活动拼音 | 有草稿、无拼音 | 没有活动会话 |
|---|---|---|---|
| 字母 | 更新拼音与候选 | 开始新的拼音段 | 开始输入 |
| 数字 1–7 | 选择对应候选到句子编辑区 | 作为数字进入草稿 | 常规输入数字 |
| 空格 | 选择当前候选到句子编辑区 | 在草稿中插入空格 | 正常处理空格 |
| ↑ / ↓ | 移动候选选择 | 移动编辑光标，遵循文本布局 | 不拦截 |
| PageUp / PageDown | 候选翻页 | 不占用宿主的翻页用途 | 不拦截 |
| ← / →、Home / End | 交给拼音引擎处理当前组合 | 编辑区内移动光标 | 不拦截 |
| Backspace / Delete | 修改当前拼音 | 修改句子草稿 | 不拦截 |
| Enter | 接受当前中文候选并提交中文整句 | 提交中文整句 | 不拦截，让宿主正常处理 |
| Ctrl+Enter | 提示“请先确认当前中文候选”，不提交 | 当前英文完整且匹配草稿时提交英文，否则只提示 | 不拦截 |
| Ctrl+J | 有有效完整英文时切换讲解 | 同左 | 不拦截 |
| Esc | 只取消当前拼音段 | 先收起讲解；已收起则取消草稿 | 不拦截 |
| Shift | 不破坏正在编辑的句子 | 不自动提交草稿 | 单独按下并释放可切换中英文直输 |
| Win+Space | 交给系统 | 交给系统，终止本次上下文 | 交给系统 |

Ctrl+Enter 被消费后不再向宿主透传，避免触发聊天软件发送。鼠标点击按钮与对应快捷键使用同一条提交路径，不能重复提交。

## 6. 焦点规则

输入浮窗不是一个可激活的普通文本窗口。它显示编辑内容、光标与选区，但实际按键和 TSF 文档上下文仍归原宿主输入控件。原生实现必须使用不激活窗口和命中测试，将点击操作转换为输入服务命令；不可直接依赖一个会获得焦点的 WPF TextBox。

- 点击中文选词、英文提交、讲解开关，不改变宿主焦点。
- 打开普通设置窗口前，若有未提交草稿，提示先输入或取消当前句子；不静默转移草稿到设置页。
- 焦点移到另一个宿主 / 文本框：隐藏浮窗，取消请求，清理会话。不自动提交，也不复用到新上下文。此“失焦取消”属于本版明确的工程默认。
- 输入法切换、宿主退出、锁屏、安全桌面同样终止会话。
- 提交前再次验证目标上下文仍然有效；验证失败只取消提交。

## 7. 状态设计与文案

| 状态 | 英文区内容 | 主要操作 |
|---|---|---|
| 空草稿 | “输入中文，看看英语怎么说。” | 不显示可提交内容 |
| 首次翻译 | 稳定占位，“正在翻译…” | 输入中文可用；英文禁用 |
| 流式返回 | 逐步显示英文，标记“生成中” | 英文禁用，不读成已完成结果 |
| 继续输入 | 保留最近结果，标记“更新中” | 旧结果不可提交 |
| 当前结果就绪 | 只显示一条完整英文，“就绪” | 英文可用，可展开讲解 |
| 未配置 | “连接 DeepSeek 后显示英文。” | 打开设置；中文可用 |
| 网络失败 | “暂时无法翻译，中文输入仍可用。” | 重试；输入中文 |
| 凭据无效 | “API Key 无效，请在设置中检查。” | 打开设置 |
| 余额不足 | “DeepSeek 余额不足。” | 设置中查看服务商入口 |
| 请求限速 | “服务繁忙，稍后重试。” | 避免连续自动重试 |
| 讲解加载 | 在原位置显示简短占位 | 不影响中文和英文提交 |
| 讲解失败 | “讲解暂时不可用。” | 局部重试，不清空翻译 |

旧结果与新结果只占同一个英文区域，不能演变成历史列表。新内容开始修改时，旧讲解立即折叠并失效；用户可在新结果完成后重新打开。

## 8. 设置窗口

桌面标准窗口，建议 640 × 560 DIP，可键盘导航。分为：

1. **翻译服务**：DeepSeek；密码类型的 API Key 输入；连接状态；“测试连接”“保存”。测试使用固定短语，不携带草稿，可产生极少量 API 费用。产品不记录 API Key 明文。
2. **外观**：跟随系统 / 浅色 / 深色，标准 / 紧凑。默认跟随系统。
3. **快捷键**：展示本版固定快捷键，不在首版加入复杂自定义映射系统。
4. **关于**：版本、开源许可、服务商入口。说明本机不保存输入记录。

保存的配置只有凭据和外观等非内容设置。原型里的 Key 控件是禁用的示例占位，不能用于输入真实凭据；测试连接仅演示反馈，保存只在页面内存生效。

## 9. 原型操作说明

- 默认展示“我今天累坏了，想早点睡。”，可以展开讲解或选择中文 / 英文输入。
- 点击外部示例句可切换不同自然表达；直接修改中文时，仅有内置例句能得到模拟翻译，其余内容显示明确的演示提示。
- “拼音选字”演示 `shui` 的候选进入内部句子缓冲，不直接输入到宿主。
- “持续更新”通过预设句子序列演示连续变化中的周期快照；动画延迟不是 API 测量值。
- “异常状态”演示断网、未配置、凭据错误及讲解失败；仍可提交中文。
- “设置”展示外观和凭据配置布局。
- 原型使用浏览器 textarea 模拟编辑，实际会获得浏览器焦点；原生焦点与 TSF 行为必须另做技术验证。
