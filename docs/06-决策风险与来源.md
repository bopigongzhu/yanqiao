# 06 · 决策、风险与来源

## 1. 已由用户决定

| 决策 | 结果 |
|---|---|
| 首发平台 | Windows 11 |
| 产品形态 | 能在不同软件中使用的系统输入法 |
| 原输入方式 | 微软拼音 + 全拼；可切换到新输入法，只需习惯相近 |
| 核心路径 | 中文 → 一条自然英文 → 主动选择输入中文或英文 |
| 中文缓冲 | 在输入法内部组织整句，不先输入到宿主再替换 |
| 展示与刷新 | 中文 / 英文同时可见；持续打字也定期更新 |
| 学习目标 | 看得懂但不擅长组织口语，学习更自然的母语者表达 |
| 讲解深度 | 中文解释重点词、短语、句型，少量例句；默认收起 |
| 速度期望 | 一次翻译请求到结果 1 秒以内 |
| 服务与费用 | 接受联网和 API 费用；DeepSeek 为当前首选；各自配置 Key |
| 使用者 | 自己和少量朋友 |
| 排除项 | 练习记录、收藏、朗读完全不要 |
| 安卓 | 等 Windows 版完成并验证成功后再考虑 |
| 资源性能 | 需要优化并明确内存、CPU 占用；具体数值尚未实测 |

## 2. 本次提出的工程与设计默认项

这些用于使开发方案可执行，并非用户已逐项指定。后续根据实测可以修订，修订时记录影响。

| 编号 | 默认项 | 理由 / 可调整边界 |
|---|---|---|
| D01 | 暂定名称“言桥” | 用于界面排版，可更名 |
| D02 | C++20 TSF + librime + Win32 / DirectWrite 辅助进程 | 用户补充性能要求后选原生主方案；需验证焦点、无障碍与许可 |
| D03 | Windows 11 x64 优先，支持 x86 宿主；ARM64 暂缓 | 限定首轮构建与测试范围 |
| D04 | DeepSeek Flash 非思考模式 | 以低延迟为验证起点，版本在开工时固定 |
| D05 | 每 100ms 检查，最短 500ms 发起一次翻译 | 持续刷新与请求成本的起始折中 |
| D06 | Enter 中文、Ctrl+Enter 英文、Ctrl+J 讲解 | 区分选词、提交与学习，需验证宿主快捷键冲突 |
| D07 | 浮窗 560 DIP；支持 440 DIP 紧凑布局 | 单句可读性与遮挡面积平衡 |
| D08 | 默认跟随系统主题，青绿主色 | 安静、适合长时间使用 |
| D09 | 300 字符草稿上限 | 防止输入法退化为长文编辑器；可依据实测调整 |
| D10 | 自然通用口语，默认美式常见拼写 | 用户未指定英美偏好，不强制地域俚语 |
| D11 | 失去原文本上下文就取消未提交草稿 | 防止串窗口；需在引导中清楚说明 |
| D12 | 默认不持久化输入引擎学习数据 | 与“不保存内容”的产品承诺一致 |
| D13 | 以典型样例完整结果 p95 ≤ 1 秒作为验收建议 | 不混淆首内容时间，不保证所有网络条件 |
| D14 | 单宿主活跃 ≤120 MiB、3 宿主 ≤180 MiB、空闲 CPU ≤0.1% 的起始预算 | 属于设计目标；口径见性能文档，真实占用待测 |

## 3. 风险与验证路径

| 风险 | 影响 | 验证 / 处理 |
|---|---|---|
| 云 API 无法稳定在 1 秒内完成 | 核心体验不达预期 | M2 优先测量，优化短提示词、连接与调度；保留真实结论 |
| 外置草稿和宿主 TSF 行为不兼容 | 未确认中文提前出现、焦点丢失 | M1 在记事本、Edge 证明；失败时解决架构问题，不偷改流程 |
| 自绘不激活编辑困难 | 点击后输入到错误窗口、无障碍不完整 | Win32 焦点实验，UI Automation 与显示缩放测试 |
| 高速打字导致所有结果过期 | 只显示加载、英文无法选择 | 一活跃一待发、周期发送、旧快照可预览但禁提交 |
| 误提交旧译文或重复提交 | 错误文字进入宿主 | session + revision + context 校验与原子提交状态 |
| 词库许可与数据来源混淆 | 无法合理分发 | 引擎与词库分别核对并保留来源、许可 |
| 引擎学习或诊断文件保存输入 | 违反不保留内容的范围 | 禁用持久学习；检查合成标记是否出现在文件与转储中 |
| 提升权限 / 自绘 / 远程控件不兼容 | 无法覆盖部分程序 | 分项测试并列明，不用全局键盘钩子回避问题 |
| 模型给出不自然或失真的表达 | 错误学习 | 人工口语与语义评估，提示词版本化，保留反例 |
| 朋友不会配置 Key | 初次使用困难 | 单页设置 + 明确连接测试；不引入共享 Key 或账号系统 |
| 每个宿主重复加载词典 | 多应用使用时内存增长 | 进程内复用、测量私有与共享页；超预算时验证集中引擎方案 |
