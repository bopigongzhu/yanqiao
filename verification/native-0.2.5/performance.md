# 0.2.5 · 候选缓存、词频查询与短时资源报告

日期：2026-10-08。Windows 11（10.0.26200），Ryzen 7 5800H，16 逻辑处理器；两块屏幕分别为 100% 和 150% 缩放。本轮没有云端请求，未操作用户的微信或浏览器。

## 候选分页的同条件对比

用同一脚本分别启动 0.2.4 与 0.2.5 的自有无界面辅助进程，使用独立、空词频和真实 Rime；输入 `s`，连续三轮各遍历 154 页再回到第一页，共 924 次 IPC 操作。逐页序列摘要相同，没有丢失、增加或改变候选顺序。

| 指标 | 0.2.4 | 0.2.5 |
|---|---:|---:|
| IPC 操作 p95 | 1.186 ms | 1.179 ms |
| IPC 操作最大值 | 3.909 ms | 3.042 ms |
| 采样最大 Private Bytes | 5.020 MiB | 4.758 MiB |
| 第三轮取消后 Private Bytes | 4.781 MiB | 4.578 MiB |

这是每版一次、约 1.47 秒的短样本，包含 Python 轮询等待、初始拼音输入和取消操作；没有实际绘制，不是宿主按键到屏幕的延迟。内存差异较小，不能据此承诺所有使用场景的下降比例，短区间 CPU 计数也不用于判断日常 CPU 改善。

更直接的改进是缓存数量有界：最多 42 个前部引用、5×7 个尾部引用、32 个定位点。普通候选只缓存原始序号，文字和读音按需获取；个人注入词条的文本与读音合计最多 2,688 字节。专项检查中最多 64 个引用、5 页、4 个定位点、6 字节注入文本与读音；对应 1,706 项功能断言通过。这不包含 Rime 内部缓存、当前输入缓冲或绘图资源。

原始证据：[旧版样本](paging-before.json)、[新版样本](paging-after.json)、[原生分页检查](paging-report.json)。

复现命令（另取报告名以保留已测结果）：

```powershell
python tools/benchmark_paging.py --bin build/0.2.4/x64/bin --report verification/native-0.2.5/paging-before-repeat.json
python tools/benchmark_paging.py --bin build/0.2.5/x64/bin --report verification/native-0.2.5/paging-after-repeat.json
```

## 词频查询

完整回归中的 10,000 条同读音合成表：查询 p95 **0.540 ms**，该测试保存／查询阶段私有内存增量 **1.352 MiB**。匹配算法使用固定数组，避免为每条词频重复分配音节和状态容器。此数据不是实际宿主延迟或整个词频功能的内存成本；详见 [完整输出](ctest.txt)。

## 5 分钟移动与绘制

自有隐藏原生编辑窗口和辅助进程持续移动、跨屏、实际 Direct2D 绘制以及取消／重建拼音组合。运行 **300.047 秒**，31 个资源样本，6 项检查通过；以第 30 秒样本作为预热后基线。CPU 使用首末样本间隔 **299.719 秒**，按整机 16 逻辑处理器归一化。

| 指标 | 辅助进程 | 自有原生试用宿主 |
|---|---:|---:|
| 预热后 Private Bytes 范围 | 61.344–61.598 MiB | 2.109–2.203 MiB |
| 结束 Private Bytes | 61.469 MiB | 2.188 MiB |
| 结束较第 30 秒 Private Bytes 增量 | −0.129 MiB | +0.078 MiB |
| 采样最大 Working Set | 49.102 MiB | 12.324 MiB |
| 预热后句柄范围 | 416–434 | 149–151 |
| 首样本 → 结束句柄 | 424 → 434 | 150 → 149 |
| CPU 时间增量 | 6.266 秒 | 2.516 秒 |
| 平均 CPU（整机） | 0.131% | 0.052% |
| 平均 CPU（单核等效） | 2.090% | 0.839% |

两进程合计平均 CPU **0.183%**。辅助进程预热后私有内存未见持续增长；句柄会波动，结束比首样本多 10 个，不能用本次短样本排除长期资源泄漏。

Private Bytes 表示私有提交量，Working Set 包含共享页，两者不能相加当作物理内存消耗；最大值是约 10 秒间隔样本中的最大值，不代表瞬时峰值。数据不包含 Python 测试控制器，隐藏试用窗口也不等于实际 TSF 宿主。与 0.2.4 的绘制样本属于相同类型负载，但各只有一轮，不能将整体内存或 CPU 差异全部归因于本次代码。

另外，无界面且未主动绘制的集成检查测得辅助进程 Private Bytes **4.266 MiB**、Working Set **19.434 MiB**；10.015 秒空闲样本未记录 CPU 时间增量。不能用该低值代表显示浮窗后的占用。

原始证据：[负载样本](tracking-load.json)、[计算结果](tracking-statistics.json)、[集成样本](integration-report.json)、[完整回归及源码摘要](summary.json)。
