# 0.2.4 · 浮窗跟随短时资源报告

日期：2026-10-08。版本：0.2.4-alpha。本地功能回归及一次 300 秒持续负载通过；本报告不判定完整性能预算或 8 小时耐久通过。

## 环境和负载

- Windows 11 Home China，10.0.26200；AMD Ryzen 7 5800H，16 逻辑处理器。系统可见内存约 13.86 GiB；采集环境信息时电源方案为 PowerX v2，未修改系统设置。
- 两块显示器：2560×1440、2560×1600；本轮 DPI 回归检测到 100% 和 150% 缩放。
- 使用独立测试作用域、自有隐藏原生编辑窗口与辅助进程。循环移动窗口、跨屏、直接调用真实 Direct2D 绘制并反复取消／重建 `ni` 拼音组合。引擎为实际 Rime，未发送云端请求。
- 持续阶段 300.031 秒；每约 10 秒采样一次，附结束采样，共 31 个样本。首末样本间隔 299.688 秒，CPU 平均值按此间隔计算。第 30 秒样本作为预热后比较基线。
- 仅计入辅助进程与自有原生试用宿主；不计 Python 控制器，不代表注入微信、浏览器、记事本的 TSF 增量。隐藏窗口不能替代真实软件的屏幕可见性验收。

## 结果

| 指标 | 言桥辅助进程 | 自有原生试用宿主 |
|---|---:|---:|
| 首样本 Private Bytes | 60.246 MiB | 2.113 MiB |
| 预热后 Private Bytes 范围 | 62.355–62.570 MiB | 2.016–2.203 MiB |
| 结束 Private Bytes | 62.570 MiB | 2.172 MiB |
| 结束较第 30 秒 Private Bytes 增量 | +0.023 MiB | +0.063 MiB |
| 采样最大 Working Set | 53.117 MiB | 12.313 MiB |
| 句柄范围 | 419–430 | 149–151 |
| 首样本 → 结束句柄 | 424 → 426 | 150 → 149 |
| CPU 时间增量 | 5.375 秒 | 1.531 秒 |
| 平均 CPU（整机 16 逻辑处理器归一化） | 0.112% | 0.032% |
| 平均 CPU（单核等效） | 1.794% | 0.511% |

两个受测进程合计平均 CPU 为 **0.144%**。公式为 `CPU 时间增量 / (299.688 × 16) × 100%`。Private Bytes 是私有提交量，Working Set 是包括共享页的工作集，两者不能相加称为物理内存消耗；表内最大值是离散样本的最大值，不是瞬时峰值。

本次辅助进程预热后的私有内存没有出现持续增长趋势，结束较第 30 秒增加约 24 KiB；句柄有波动且会回落。一次 5 分钟样本不能排除长期泄漏，也不能证明 CPU 短峰、8 小时净增长或三宿主合计预算达标。

另一次无界面、未主动绘制的集成检查测得辅助进程 Private Bytes 4.301 MiB、Working Set 19.461 MiB；10.013 秒空闲期未记录 CPU 时间增量。它与本次绘制负载条件不同，不能用该低值代表正常显示浮窗后的占用，也不能将两次差值全部归因于某个图形组件。
