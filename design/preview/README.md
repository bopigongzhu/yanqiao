## 验证范围

2026-10-05 使用 Microsoft Edge 无头浏览器与 Playwright 进行了离线交互检查，机器可读结果见 [verification.json](verification.json)。

已检查 27 项，包括：

- 初始结果、讲解开关和 Ctrl+J；
- 中文 / 英文提交、清空当前草稿与讲解；
- 拼音候选留在内部编辑区，不提前插入宿主；
- 持续更新、旧英文立即失效、清空后迟到结果失效；
- 未收录内容不伪装成真实翻译；
- 断网、Key 错误、讲解错误及重试；
- 原型拒绝输入真实 Key，模拟连接不发起网络请求；
- 深色主题、440px 紧凑布局；
- 1000 / 820 / 390px 窗口无横向溢出；
- 无浏览器运行错误、无外部网络调用。

截图在结束过渡动画后保存，并复核浅色、深色、讲解、设置和窄窗口的布局。主要正文、次级正文和主按钮颜色对比已检查；禁用状态、边框与装饰色另行区分，不宣称完成整个无障碍审计。

## 不代表什么

这次验证不代表已经完成 Windows TSF 注册、真实全拼词库、宿主焦点管理、API 翻译、API 延迟、内存 / CPU 实测或安装包。浏览器页面只展示设计与部分交互，真实实现和资源测量按开发文档执行。
