# 言桥 0.2.5-alpha · 本地开发试用包

本轮完善候选与常用词稳定性：候选缓存只保留固定数量的引用，文字按需读取；增加加密词频副本与损坏恢复，清除时同步清理副本和旧保存任务；全拼替代形式 `lue/lve`、`nue/nve` 及 j/q/x/y 后的 u/v 共用正确读音，无法唯一确定读音的简拼不误学习。保留浮窗位置跟随、高 DPI、主动退出、断连恢复、7 候选及独立讲解重试。

早期版本的一条固定合成短句真实讲解检查成功，约 1.13 秒；尚未对所有句子或翻译延迟进行统计验收。本轮没有新增云端请求。**运行前先保存试用文本，关闭旧窗口并退出旧托盘辅助进程。**

Windows 11 x64；内含 64 / 32 位 TSF 桥接组件。用户在 0.2.4 交付后反馈当前使用未发现新问题；本轮只读诊断显示系统注册仍为 0.2.3，因此不能视为系统端已换用 0.2.4。本包同时包含这些版本的修复，完成本地候选、词频恢复与清除、窗口和 IPC 回归；升级后需在微信、浏览器和记事本中复测，完整跨应用、真实 API 与 8 小时耐久验收尚未完成。

同条件 154 页、924 次 IPC 操作对比中，新旧版候选序列相同，操作响应 p95 都约 1.18 ms；新版本缓存数量有界。此为无界面合成负载，不能代替真实软件中的按键到绘制延迟。完整报告保存在项目 `verification/native-0.2.5`。

一次 5 分钟实际 Rime／Direct2D 移动与绘制样本中，辅助进程预热后私有内存为 61.34–61.60 MiB，平均 CPU 0.131%（16 逻辑处理器）；不含实际软件 TSF 增量和联网翻译。不能视为完整性能或 8 小时耐久验收。

## 直接试用

1. 双击 `Start-Trial.cmd`。
2. 输入 `nihao`，空格选词，Enter 输入整句中文。选词时中文留在浮窗，不会提前进入文本框。
3. 双击 `Settings.cmd`，在程序里填写个人 DeepSeek API Key 并保存，再点“测试连接”。测试会发送固定短句并产生少量用量。Key 由 Windows 凭据管理器保存。
4. 当前翻译完整、中文候选已确认后，用 Ctrl+Enter 输入英文；Ctrl+J 查看讲解；Esc 逐层取消；无草稿时 Shift 切换中 / 英模式。

未配置 Key 时仍可试用中文。程序没有练习记录、收藏、朗读功能，不保存输入历史。实际输入时 DeepSeek 会接收当前草稿快照；讲解只在展开时请求。

默认保存已有词条的文本、完整读音、聚合权重及更新日，用当前 Windows 用户 DPAPI 加密存于 `%LOCALAPPDATA%\EShuRu\word-frequency.dat`。不保存连续原句、英文或逐次选择记录。关闭学习会保留文件但恢复基础排序；清除操作移除个人权重，不影响 Key。无法确认读音的词和动态组句仍可输入，但不学习。未提交的草稿不参与后续个性化排序。

0.2.5 同时保存一份 `word-frequency.dat.bak` 加密聚合副本；主文件损坏或缺失时尝试恢复并提示。副本可能落后于最近一次主文件写入，不是逐次历史。清除成功会持久化空主文件、移除副本及临时文件；清理失败会提示重试，不能视为已清除。升级兼容旧版词频格式。

窗口关闭后辅助进程可能继续驻留托盘，右键托盘图标 → “退出辅助进程”。不同目录的试用包与安装版不要同时运行辅助进程；切换版本前先退出原来的实例。

## 安装与升级

可先用普通 PowerShell 执行 `& .\installer\diagnose.ps1 -RequirePackage`，只检查文件、位数、注册路径与当前用户键盘列表。旧版无法退出时先执行 `& .\EShuRuMaintenance.exe --stop-installed`：仅停用当前会话中的言桥并请求安装版辅助进程正常退出，不关闭其他应用、不修改默认输入法或启用列表。执行后确认进程已退出，再安装。

使用 64 位管理员 PowerShell，在本目录执行：

```powershell
& .\installer\install.ps1
```

脚本安装到 `%ProgramFiles%\EShuRu`，并把“言桥全拼”加入当前用户的键盘列表；然后通过 Win+Space 选择“言桥全拼”。如果安装时使用了另一个管理员账户，请以日常用户运行一次 `EShuRuMaintenance.exe --register-input`，或打开一次设置完成修复。必要时注销并重新登录，检查中文语言的键盘列表。不会修改默认输入法。当前 Alpha 未签名，脚本不会自动修改系统执行策略。

注销：`& .\installer\uninstall.ps1`。默认保留文件；退出辅助进程并关闭相关应用后，用 `-RemoveFiles` 可清理固定安装目录。DLL 被占用时需关闭应用或注销登录后再清理。

配置和 Key 默认保留。需删除 Key 时，在卸载前使用设置中的“删除密钥”，或删除本用户凭据管理器中的 `EShuRu/DeepSeek`。

卸载加 `-RemoveWordFrequency` 可删除运行该脚本的 Windows 账户的个人词频；如果管理员账户与日常账户不同，请在日常账户的设置中清除。升级前会将现有安装备份到相邻的 `EShuRu.backup-<随机标识>` 目录，控制台显示路径。当前是手动恢复备份，尚未验证完整事务升级／自动回退。

## 当前限制

- 辅助进程断连后可以重新连接；未提交草稿不能恢复。浮窗 DPI 与位置跟随已实现；跟随依赖宿主提供有效光标几何信息，宿主暂时无法提供位置时面板隐藏。设置窗口全面 DPI / 无障碍和完整系统升级验收仍未完成。
- 主动退出后需手动打开 `Settings.cmd` 或 `Start-Trial.cmd` 恢复。自动启动暂停位保存于当前用户 `Software\EShuRu\Runtime`，只含布尔状态，不含输入文本。旧宿主可能仍持有旧 DLL，关闭宿主或注销后才会全部换用新组件；新版主程序入口也会拒绝旧 DLL 在暂停状态下的启动请求。
- 已验证本地全拼核心、IPC 和试用窗口，安全模式 TSF 生命周期通过；普通宿主系统输入仍需实际安装测试。
- 资源测量见项目 `verification/native-0.2.5`；无界面与合成测试不代表实际宿主完整资源验收。
- 翻译完整结果 1 秒目标尚未经过真实 API 测试。
- 预编译 Rime 包含 GPL-3.0 octagram 插件。此为本地开发包，尚未对外发布；发行前的依赖替换或源码 / 许可安排见 [第三方说明](licenses/THIRD_PARTY_NOTICES.md)。
